
# Summer Products Analysis | Power BI

## Project Overview
This project analyzes summer product sales and performance using Power BI. The goal is to identify sales trends, evaluate product ratings, compare merchants, and explore pricing patterns.

## Tools and Skills
- Power BI Desktop
- Power Query – data cleaning and transformation
- DAX – calculated measures and KPIs
- Interactive dashboards and data visualization
